1. Claudeとは？

ClaudeはAnthropic社が開発した生成AIです。

文章作成、要約、分析、企画書作成などを得意とし、 業務効率化や情報整理に活用できます。

まずは以下のような業務から始めるのがおすすめです。

  • メール作成
  • 議事録作成
  • SNS投稿作成
  • レポート要約
  • 企画書作成

3. Claudeで業務効率化する

AI活用の目的は「AIを使うこと」ではありません。

単純作業を減らし、人が企画・判断・コミュニケーションに集中することです。

業務 従来 Claude活用後
議事録作成 60分 10分
SNS投稿作成 30分 5分
企画書作成 3時間 30分
レポート作成 2時間 15分
競合調査 2時間 20分

まず取り組むべき業務

  • メール作成
  • 議事録作成
  • SNS投稿作成
  • 企画書作成
  • 月次レポート作成

これらは効果が出やすく、初心者にもおすすめです。

5. GitHubとは？

GitHubは作成したファイルを保存・管理するサービスです。

Wordの保存先がOneDriveなら、 プログラムの保存先がGitHubです。

GitHubでできること

  • ファイル保存
  • バージョン管理
  • 共同編集
  • Web公開
  • バックアップ

Claude Codeで作成したファイルは、 GitHubへ保存することで安全に管理できます。

6. GitHub Pagesで公開する

GitHub Pagesは無料でWebサイトを公開できるサービスです。

サーバー契約は不要です。

STEP1

GitHubへログイン
New Repositoryを作成

STEP2

Add file → Create new file
ファイル名を index.html にする
Claudeが作成したHTMLを貼り付ける

STEP3

Commit changes を押す

STEP4

Settings → Pages
Deploy from a branch
Branch → main
Folder → /(root)
Save

STEP5

数分後にURLが発行されます。 

https://ユーザー名.github.io/リポジトリ名/

このURLを共有するだけで、 誰でもページを閲覧できます。

更新方法

index.html を編集し、 再度「Commit changes」を押すだけです。

数分後に自動で公開ページへ反映されます。

まとめ

Claudeには大きく3つの活用方法があります。

  • Claude Chat：文章作成や分析を行うAIアシスタント
  • Claude Cowork：事務作業を支援するAI
  • Claude Code：システムやWebサイトを開発するAI

まずはClaude Chatで日常業務を効率化し、 次にClaude Codeを活用して業務改善ツールやダッシュボードの作成に挑戦してみましょう。

AI活用の目的は、 AIを使うことではありません。

作業を減らし、 人が企画・判断・コミュニケーションに集中することです。

特にDMOでは、

  • データ収集
  • レポート作成
  • SNS分析
  • Web更新
  • 資料作成
をAIへ任せることで、 戦略立案や地域事業者との連携により多くの時間を使えるようになります。
