2. Claudeの3つの活用方法

  • データ分析

5. GitHubとは？

GitHubは作成したファイルを保存・管理するためのサービスです。 Wordの保存先がOneDriveなら、 プログラムやWebサイトの保存先がGitHubです。

保存

作成したファイルを安全に保管

履歴管理

いつでも過去の状態へ戻せる

共同作業

複数人で編集可能

9. まとめ

Claudeには3つの役割がある

サービス 役割 用途
Claude Chat AIアシスタント 文章作成・分析
Claude Cowork AI事務職員 資料作成・整理
Claude Code AIエンジニア システム開発

まず取り組むべきこと

  1. Claude Chatで文章作成を行う
  2. 議事録や企画書作成を効率化する
  3. GitHub Pagesで情報共有サイトを作る
  4. Claude Codeで業務ツールを作る
  5. 観光DX基盤を構築する

AI活用の本当の目的

AIを使うことではありません。

単純作業を減らし、 人が企画・判断・コミュニケーションに 集中することです。

特にDMOや自治体では、 データ収集やレポート作成をAIへ任せることで、 地域事業者との連携や観光戦略の立案に より多くの時間を使えるようになります。
