Claude活用ガイド

AIを活用して業務効率化し、Webページとして公開するまでの手順

1. Claudeとは？

Claudeは文章作成、要約、分析、企画書作成を得意とするAIです。

まずは以下のような業務から始めるのがおすすめです。

  • メール作成
  • 議事録作成
  • SNS投稿作成
  • レポート要約
  • 企画書作成

2. Claudeで業務効率化する

業務 従来 Claude活用後
議事録作成 60分 10分
SNS投稿作成 30分 5分
企画書作成 3時間 30分
レポート作成 2時間 15分

3. Claude Codeとは？

Claude CodeはAIエンジニアです。

自然言語で指示するだけで、 Webサイトやダッシュボードを作成できます。

指示例

観光マーケティングダッシュボードを作成してください。

条件

・スマホ対応
・観光客数グラフ
・宿泊者数グラフ
・Instagram分析
・GA4分析

4. GitHubとは？

GitHubは作成したファイルを保存・管理するサービスです。

Wordの保存先がOneDriveなら、 プログラムの保存先がGitHubだと考えてください。

5. GitHub Pagesで公開する

STEP1 リポジトリ作成

GitHubへログインし「New Repository」を作成

STEP2 index.html作成

Add file → Create new file
ファイル名を index.html にする
Claudeが生成したHTMLを貼り付ける

STEP3 保存

Commit changes

STEP4 GitHub Pages設定

Settings → Pages
Source ↓ Deploy from a branch
Branch ↓ main
Folder ↓ /(root)
Save

STEP5 完成

数分後に以下のようなURLが発行されます。 

https://ユーザー名.github.io/リポジトリ名/

このURLを共有するだけで、 誰でもページを見ることができます。

7. 学習ロードマップ

レベル 内容

中級 資料作成・分析
中上級 Claude Codeでサイト作成
上級 GitHub Pages公開
実務活用 業務自動化・ダッシュボード構築

まとめ

AI活用の目的はAIを使うことではありません。

単純作業を減らし、 人が企画・判断・コミュニケーションに集中することです。

まずはClaudeで文章作成や資料作成から始め、 次にClaude Codeで業務ツールを作り、 GitHub Pagesで公開してみましょう。
