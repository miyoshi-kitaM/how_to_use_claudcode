Claude活用ガイド

AIを活用して業務効率化し、Webページとして公開するまでの手順

1. Claudeとは？

Claudeは文章作成、要約、分析、企画書作成を得意とするAIです。

まずは以下のような業務から始めるのがおすすめです。

  • メール作成
  • 議事録作成
  • SNS投稿作成
  • レポート要約
  • 企画書作成

2. Claudeの3つの活用方法

Claudeには大きく3つの活用方法があります。

サービス 役割 主な用途
Claude Chat AIアシスタント 文章作成・要約・企画立案・分析
Claude Cowork AI事務職員 ファイル整理・資料作成・PC作業代行
Claude Code AIエンジニア Webサイト・アプリ・ダッシュボード開発

Claude Chat

最も利用者が多いClaudeです。

ChatGPTと同じように会話しながら利用します。

できること

  • メール作成
  • 議事録要約
  • SNS投稿作成
  • 企画書作成
  • データ分析
  • アイデア出し

DMOでの活用例

  • Visit Ozu特集記事作成
  • Instagram投稿作成
  • 補助金申請書作成
  • 月次レポート作成

Claude Cowork

Claude Coworkはパソコン上の作業を支援するAIです。

Chatで指示するだけで、 ファイル整理や資料作成などを実行できます。

できること

  • フォルダ整理
  • ファイル検索
  • Excel整理
  • 資料作成
  • 議事録作成
  • 定型業務の自動化

DMOでの活用例

  • 写真データ整理
  • 観光客アンケート集計
  • 議事録作成
  • 報告書作成

イメージとしては 「優秀な事務職員」が1人増える感覚です。

Claude Code

Claude Codeはソフトウェア開発に特化したAIです。

自然言語で指示するだけで、 プログラムやWebサイトを作成できます。

できること

  • Webサイト作成
  • ダッシュボード作成
  • 業務システム作成
  • データ連携
  • API連携
  • 自動化ツール開発

DMOでの活用例

  • 観光マーケティングダッシュボード
  • 宿泊統計管理システム
  • SNS分析ツール
  • 観光データ可視化

イメージとしては 「優秀なエンジニア」が1人増える感覚です。

どれを使えばいいの？

やりたいこと おすすめ
文章作成 Claude Chat
企画書作成 Claude Chat
ファイル整理 Claude Cowork
報告書作成 Claude Cowork
ホームページ作成 Claude Code
ダッシュボード作成 Claude Code

初心者はまずClaude Chatから始めることをおすすめします。

文章作成や企画書作成に慣れたらClaude Cowork、 さらに業務改善を進めたい場合はClaude Codeへ進みましょう。

4. Claude Codeとは？

Claude CodeはAIエンジニアです。

自然言語で指示するだけで、 Webサイトやダッシュボードを作成できます。

指示例

観光マーケティングダッシュボードを作成してください。

条件

・スマホ対応
・観光客数グラフ
・宿泊者数グラフ
・Instagram分析
・GA4分析

5. GitHubとは？

GitHubは作成したファイルを保存・管理するサービスです。

Wordの保存先がOneDriveなら、 プログラムの保存先がGitHubだと考えてください。

6. GitHub Pagesで公開する

STEP1 リポジトリ作成

GitHubへログインし「New Repository」を作成

STEP2 index.html作成

Add file → Create new file
ファイル名を index.html にする
Claudeが生成したHTMLを貼り付ける

STEP3 保存

Commit changes

STEP4 GitHub Pages設定

Settings → Pages
Source ↓ Deploy from a branch
Branch ↓ main
Folder ↓ /(root)
Save

STEP5 完成

数分後に以下のようなURLが発行されます。 

https://ユーザー名.github.io/リポジトリ名/

このURLを共有するだけで、 誰でもページを見ることができます。

まとめ

AI活用の目的はAIを使うことではありません。

単純作業を減らし、 人が企画・判断・コミュニケーションに集中することです。

まずはClaudeで文章作成や資料作成から始め、 次にClaude Codeで業務ツールを作り、 GitHub Pagesで公開してみましょう。
